- **Key architectural decisions**:
  - All admin roles share the /admin route prefix with a smart layout that infers role from path.
  - Every privileged operation (approve, reject, escalate, suspend, role change, payout, refund, setting update, integration toggle) records an audit log entry via auditLogRepo.record().
  - Audit logs are append-only — no UPDATE or DELETE in the contracts.
  - Last-super-admin guard: the dev adapter throws if you try to demote or suspend the last active super_admin.
  - Demo mode is clearly labelled on every admin page via DemoModeBanner.
  - Sensitive actions (payout reverse, user suspend, integration disable) use AlertDialog with required reasons.
  - The permission matrix is visible in the Roles page (read-only in demo; production changes require reauth).
  - Backend verification status is surfaced prominently — payments show "Backend-confirmed" vs "Unverified", payouts show "Backend-verified settlement" when settled.
- **Existing functionality preserved**: All marketplace routes (student, landlord, manager, agent) remain unchanged. The role-shell's switch-role menu now shows all 8 roles split into Marketplace and Administrative groups.
